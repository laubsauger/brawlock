The release includes King of the Hill (custom lobby option and a casual free-for-all
queue, hill visuals, HUD, announcer calls and hill-seeking bots), the server CPU work
measured in the capacity report (match state stepped in place, one pulse timer, no
loss repeats over WebSocket, bot plans and input hints inside the stream packet,
link reports once a second) and a simulation rate chosen per game server.

## Simulation rate

The tick rate is no longer a build constant. A game server runs every room at
`TICK_HZ` (`30` or `60`, default `30`); the room's welcome carries the rate and
clients switch to it. The release did not change the protected ecosystem files, so
both regions run the default 30 Hz. Running a region at 60 Hz needs `TICK_HZ=60` in
its protected `env` and a reload. Match records (ratings, history, profile totals,
analytics) keep counting time in 1/60 s at either rate, so older rows stay comparable.
Protocol 9 replaces 8: older clients see both regions as another version.
